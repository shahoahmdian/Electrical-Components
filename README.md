# یاب‌قطعه (PartFinder)
اپ اندروید (Kotlin + Jetpack Compose) برای جستجوی قطعات الکترونیکی با تایپ یا عکس.

## ساخت APK با GitHub
1. یک ریپازیتوری جدید در GitHub بسازید و همه فایل‌های این پوشه را آپلود/push کنید.
2. به تب Actions بروید؛ workflow با نام Build APK اجرا می‌شود.
3. پس از پایان، فایل APK را از بخش Artifacts دانلود کنید.

## جستجو با عکس
عکس به Anthropic API ارسال می‌شود تا مدل و نوع قطعه خوانده شود، سپس در بایگانی محلی جستجو می‌شود. کلید API را در برنامه وارد کنید.
(کلید داخل گوشی ذخیره می‌شود؛ برای انتشار عمومی از سرور واسط استفاده کنید.)

## افزودن قطعه
فایل app/src/main/assets/components.json را ویرایش کنید.

## حالت آنلاین (DigiKey)
در developer.digikey.com یک اپ بسازید (Production app با Product Information V4) و Client ID و Client Secret را در دکمه «کلیدها» وارد کنید. سپس سوییچ بالای صفحه را روی آنلاین بگذارید.

## آفلاین
بایگانی محلی و نقاشی‌های قطعات بدون اینترنت کار می‌کنند. تب «رنگ مقاومت» هم کاملاً آفلاین است.
